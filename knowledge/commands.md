# Lunae Commands

Lunae currently provides these Discord commands:

## `/lunae`

Ask Lunae a question about Lunarion.

## `/ask`

Ask a Lunarion-related question using the source-aware AI system.

## `/code`

Request Lunarion Lua code based on a description.

## `/debug`

Analyze Lunarion Lua code for likely problems.

## `/api`

Search the actual Lunarion source for an API name.

## `/themes`

Show the documented Lunarion themes.

## `/help`

Show Lunae's available commands.

## `/about`

Show information about Lunae.

All technical answers should be checked against the actual Lunarion source whenever possible.
