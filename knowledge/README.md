# Lunae Knowledge

This directory contains the technical knowledge used by Lunae.

## Lunarion.lua

`Lunarion.lua` is the primary Lunarion source reference.

Lunae should use the actual source when answering Lunarion API questions and should not invent undocumented functions or parameters.

## api.md

`api.md` contains the human-readable API notes used alongside the source.

Keep both files updated when the Lunarion API changes.
