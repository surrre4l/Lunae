# Lunae

Lunae is a Discord AI assistant specialized in the Lunarion Roblox UI library.

## Features

- Ask questions about Lunarion
- Explain Lunarion APIs
- Generate Lunarion code
- Debug Lunarion code
- Look up documented Lunarion functions
- Use the Lunarion source as the primary knowledge reference

## Commands

- `/lunae ask`
- `/lunae code`
- `/lunae explain`
- `/lunae debug`
- `/lunae api`
- `/lunae themes`
- `/lunae help`
